# Simplify

Projeto web desenvolvido com foco em prática de **HTML, CSS e JavaScript**, explorando criação de interfaces modernas, responsivas e bem estruturadas.

O objetivo do projeto é apresentar uma página visualmente organizada, com boa experiência de navegação e estrutura simples, servindo como base para estudos de front-end, landing pages e apresentação institucional.

---

## 🚀 Objetivo

O **Simplify** foi criado para praticar conceitos fundamentais de desenvolvimento web, como:

* Estruturação de páginas com HTML;
* Estilização com CSS;
* Organização visual de componentes;
* Responsividade para diferentes tamanhos de tela;
* Boas práticas de layout e apresentação;
* Uso de JavaScript para interações simples.

---

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* GitHub Pages

---

## 📌 Funcionalidades

* Página web estática;
* Layout moderno e organizado;
* Estrutura responsiva;
* Seções bem definidas;
* Código simples para estudo e evolução.
